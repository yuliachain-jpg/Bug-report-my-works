Bug Reports Portfolio( Manual QA )
Учебное портфолио баг репорты .

Цель- это показать навык поиска, воспроизведения и чёткого описания дефектов 

### Формат баг-репорта
- Summary 
- Environment 
- Precondition 
- Steps to reproduse 
- Expected result 
- Actual result 
- Severity
- Priority 
- Attachment ( скриншоты)
